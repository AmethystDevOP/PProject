# Personal Finance & Savings Tracker 💰

## Overview
A Python-based utility to help students and freelancers track their monthly spending and calculate their savings percentage. 

## Features
- Dynamic expense category input.
- Real-time savings rate calculation.
- Basic financial advice based on percentage thresholds.

## How to Run
1. Ensure you have Python installed.
2. Run `python finance_tracker.py` in your terminal.
